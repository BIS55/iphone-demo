# Кошелёк — ДЕМО для iPhone

Статичный макет экрана по мотивам пользовательских скриншотов. **Не банковское приложение.** Данные вымышлены, счета и платежи не работают.

## iPhone

1. В GitHub откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, каталог **/(root)** и нажмите **Save**.
3. После публикации откройте **https://bis55.github.io/iphone-demo/** в Safari на iPhone.
4. **Поделиться → На экран «Домой» → Добавить**. Приложение запускается отдельно от Safari.

Страница показывает заставку на 1,3 секунды, затем главный экран. Все материалы демо доступны публично через GitHub Pages. Никакой связи с реальным банком или входа в счёт нет.
